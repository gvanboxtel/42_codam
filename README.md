# 42 / Codam projects

Projects I built in the 42 Common Core at [Codam](https://www.codam.nl/). 42 does not allow publishing project source code, so this repository holds each project's README: what it does, how it works and the design choices behind it.

| Project | Language | About |
|---|---|---|
| [Libft](Libft.md) | C | Re-implementation of libc functions plus linked-list utilities, reused in later projects |
| [ft_printf](ft_printf.md) | C | `printf` with variadic arguments |
| [get_next_line](get_next_line.md) | C | Read a file line by line with a static buffer, for several file descriptors at once |
| [Born2BeRoot](Born2BeRoot.md) | Linux | A hardened server in a VM: LVM encryption, SSH, firewall, password and sudo policy |
| [push_swap](push_swap.md) | C | Sort a stack with a limited instruction set in as few moves as possible |
| [Python Modules](Python_Modules.md) | Python | Exceptions, packages, OOP and design patterns, Pydantic and functional programming |
| [Call Me Maybe](call_me_maybe.md) | Python | Function calling with a 0.6B LLM through constrained decoding |
| [Fly-in](fly_in.md) | Python | Conflict-aware path planning for multiple drones |
| [Pac-Man](Pac-Man.md) | Python | Arcade Pac-Man with procedural mazes, ghost AI and highscores (team project) |
| [RAG against the Machine](RAG.md) | Python | Retrieval-augmented generation over the vLLM codebase: BM25, semantic and hybrid search |
| [Inception](Inception.md) | Docker | NGINX, WordPress and MariaDB in self-built containers with Docker Compose (in progress) |
